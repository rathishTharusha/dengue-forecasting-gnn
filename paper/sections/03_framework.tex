\section{Proposed Framework}
\label{sec:framework}

\subsection{Problem Formulation}
We model Sri Lanka's administrative districts as nodes in a graph
$\mathcal{G} = (\mathcal{V}, \mathcal{E}, \Afix)$, where $|\mathcal{V}| = N = 25$
and $\Afix \in \R^{N \times N}$ encodes shared district boundaries. Let
$\mathbf{X} \in \R^{T \times N \times F}$ denote the spatio-temporal feature
tensor over $T = 459$ weeks (2013--2022) with $F = 11$ features: the weekly case
count plus ten climate and vegetation covariates. Given a window of $W = 3$
historical weeks, the task is to forecast incidence over the next $H = 3$ weeks
for every district.

\subsection{Learned Adaptive Adjacency}
Geographic adjacency is an imperfect proxy for transmission --- it cannot express
movement along economic corridors --- and no district-level mobility data exists
for Sri Lanka to replace it. Following Graph WaveNet~\cite{wu2019graphwavenet} we
introduce node embeddings $\mathbf{E}_1, \mathbf{E}_2 \in \R^{N \times d}$ with
$d = 10$ and learn the graph directly:
\begin{equation}
  \Aadp = \mathrm{softmax}\!\left(\mathrm{ReLU}\!\left(\mathbf{E}_1\mathbf{E}_2^{\top}\right)\right),
  \label{eq:adaptive}
\end{equation}
where $\mathrm{ReLU}$ zeroes negative affinities so the graph is sparse rather
than complete, and the row softmax makes each district's incoming weights sum
to one.

Learning $2Nd = 500$ graph parameters from 25 nodes invites overfitting, so the
learned graph is mixed with geography under a single learnable scalar $g$:
\begin{equation}
  \Ablend = \sigma(g)\,\Afix + \bigl(1-\sigma(g)\bigr)\,\Aadp .
  \label{eq:gate}
\end{equation}
At initialisation $g = 1.5$, so $\sigma(g) \approx 0.82$: training begins leaning
on geography and moves toward the learned structure only as the embeddings earn
it. Both components are row-stochastic, so $\Ablend$ is too.

Message passing follows the standard graph-convolution
form~\cite{kipf2017gcn}, applied densely over the batch:
\begin{equation}
  \mathbf{H}^{(1)} = \mathrm{ReLU}\!\left(\Ablend \mathbf{X} \mathbf{W}_1\right),
  \quad
  \mathbf{H}^{(2)} = \mathrm{ReLU}\!\left(\Ablend \mathbf{H}^{(1)} \mathbf{W}_2\right),
\end{equation}
followed by $\hat{\mathbf{Y}} = \mathrm{Linear}(\mathrm{Dropout}(\mathbf{H}^{(2)}))$.
$\Afix$ is row-normalised with self-loops, matching the normalisation the softmax
imposes on $\Aadp$ so that the two are blended on a common scale.

\subsection{Spatial Regularisation}
Weng et al.~\cite{weng2024graph} report that unconstrained message passing
propagates outbreaks into districts where none occurred. We test whether a soft
spatial constraint suppresses this:
\begin{equation}
  \mathcal{L} = \Ldata + \lambda \left(\Lsmooth + 10\,\Lcons\right),
  \label{eq:loss}
\end{equation}
where $\Ldata$ is mean squared error in log-transformed
residual-over-persistence space, $\Lsmooth$ is a graph-Laplacian penalty on
disagreement between connected districts,
\begin{equation}
  \Lsmooth = \frac{1}{B H \|\Ablend\|_1} \sum_{b,h} \sum_{i,j}
             \mathbf{A}_{\mathrm{blend},ij}
             \left(\hat{y}_{i,b,h} - \hat{y}_{j,b,h}\right)^2 ,
\end{equation}
and $\Lcons = \mathrm{mean}\bigl(\mathrm{ReLU}(-\hat{y})^2\bigr)$ penalises
negative case counts.

Two properties of this objective bear on how Section~\ref{sec:results} should be
read. First, the penalty applies to inverse-transformed case counts: the network
predicts a residual in log space, where a negative value means \emph{fewer cases
than last week} rather than a negative count, so constraining it there would
penalise any forecast of a decline. We apply it to $\log(1+\hat{y})$, since on
raw counts $\Lsmooth$ exceeds $\Ldata$ by four orders of magnitude and any usable
$\lambda$ would switch the data term off rather than weight against it. Second,
$\Lcons$ cannot bind: the inverse transform clamps at zero before
exponentiating, so counts are non-negative by construction and the
$10\,\Lcons$ term contributes nothing to the gradient under any $\lambda$. We
retain it for completeness and report $\lambda$ as controlling $\Lsmooth$ alone.

This is spatial regularisation --- no compartments, no transmission dynamics, no
mechanistic residual --- and we do not describe it as physics-informed. A soft
SEIR--SEI constraint remains future work.

\subsection{Implementation Details}
\label{sec:impl}
Node features for district $i$ at origin $t$ are the $W \times F = 33$ values of
the preceding three weeks, flattened feature-major. Targets are the next $H=3$
weekly counts, transformed twice before the loss sees them: to $\log(1+y)$, then
to a residual over persistence, so the network predicts the \emph{correction} to
last week's value rather than the level. Both transforms are inverted before any
metric is computed, and normalisation statistics come from training weeks only.

Training uses one optimiser step per window --- Adam,
$\text{lr}=10^{-3}$, weight decay $5\times10^{-4}$, gradient clipping at $5.0$,
at most 120 epochs with early stopping on validation RMSE after 25 epochs without
improvement. Dropout is $0.1$ before the prediction head. $\Afix$ is
row-normalised with self-loops. The gate is a single scalar initialised at
$g=1.5$.

The model is small: $7{,}032$ trainable parameters for $d=10$, $\text{hidden}=64$.
Every configuration trains in roughly a minute per fold on one CPU thread, and we
report the resulting cost in Section~\ref{sec:results}. Notably, single-threaded
execution is \emph{faster} than multi-threaded on this workload --- at this tensor
size the synchronisation cost exceeds the arithmetic --- so parallelism is taken
across independent runs rather than within them.

\subsection{Controlled Comparison}
The fixed-graph control is this same model with $\Ablend = \Afix$: identical
propagation path, head, optimiser and target handling, rather than a separately
implemented baseline. The distinction matters. A PyTorch Geometric
\texttt{GCNConv} baseline applies symmetric normalisation
$\mathbf{D}^{-1/2}(\mathbf{A}{+}\mathbf{I})\mathbf{D}^{-1/2}$ rather than the row
normalisation used here, so comparing against one would confound the learned
adjacency with a change of operator. All models share residual-over-persistence
forecasting, $\log(1+x)$ targets, Adam ($\text{lr}=10^{-3}$, weight decay
$5\times10^{-4}$), gradient clipping at 5.0, and early stopping on validation
RMSE.
