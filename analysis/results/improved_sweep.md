# Improved-architecture sweep
Five verified architectures under `docs/ROADMAP.md`'s frozen protocol, each with four evidence-led increments. Generated by `analysis/_build/merge_sweep.py` from the five Kaggle kernels.

Every fold is scored twice. `all windows` is what the frozen protocol reports; `artifact-free` drops the six origin-0.85 test windows touching the week-395 reporting spike, from every arm and from the floor alike. Roughly 90% of that fold's squared error comes from those six windows, and the fold ordering inverts between the two tables -- so no statement about 'the hard fold' means anything without saying which table it came from.
