## What each arm is

- **GCN (control)** (`X_gcn`): adaptive GCN, no temporal operator
- **GCN + gated TCN** (`X_gcn_gtcn`): Graph WaveNet temporal block
- **GAT** (`X_gat`): Velickovic attention, no temporal operator
- **STGAT** (`X_stgat`): GAT + LSTM
- **A3TGCN** (`X_a3tgcn`): GCN + GRU with attention over timesteps
- **GAT 1-head** (`X_gat_h1`): 7,160 params: matched to the GCN control's 7,032
- **GAT 2-head** (`X_gat_h2`): 13,624 params: matched to GCN hidden=96
- **GCN h96** (`X_gcn_h96`): 13,368 params: capacity control for GAT 2-head
- **GCN h128** (`X_gcn_h128`): 21,752 params: capacity control for A3TGCN's 23,865
